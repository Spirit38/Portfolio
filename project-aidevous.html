Aide&Vous

Application web — Plateforme de coordination et de suivi médical pour les aidants familiaux.

2ème Prix — Meilleur Prototype (IUT 2 - Département Informatique)

Cliquez sur les images pour les agrandir

🎯 Description

Aide&Vous est une application web conçue pour simplifier le quotidien des aidants familiaux. Elle permet de centraliser les informations médicales (ordonnances, contacts, rendez-vous) d'une personne dépendante et de les partager de manière sécurisée avec un "cercle de soin" (famille, infirmiers, voisins).

❓ Problématique

Les aidants sont souvent submergés par la gestion administrative et médicale (perte d'ordonnances, manque de coordination entre proches). Aide&Vous répond au besoin de centralisation, de sécurité des données de santé (contexte RGPD) et d'accessibilité rapide en cas d'urgence.

🧠 Stack Technique & Compétences

PHP 8.4 (MVC Natif) PostgreSQL Python (Tesseract OCR) Debian 13
  • Architecture : Client-Serveur / Modèle MVC (Modèle-Vue-Contrôleur) conçu de zéro.
  • Base de données : Modélisation complexe (MCD/MLD) avec PostgreSQL.
  • Sécurité : Chiffrement des documents (AES-256), Hachage Argon2, protection CSRF/XSS.
  • Système : Déploiement et configuration sur un serveur Debian sécurisé.

🚀 Fonctionnalités Clés

  • Coffre-fort numérique : Upload et analyse automatique d'ordonnances via OCR (Python).
  • Fiche d'Urgence : Génération instantanée d'une fiche récapitulative.
  • Cercle de Soin : Gestion des permissions pour inviter d'autres aidants.
  • Agenda Partagé : Suivi des rendez-vous médicaux et évènement.
  • Post-it collaboratif : Post-it virtuels pour notes rapides et partage automatique entre tous les aidants.

🤝 Travail en équipe

Projet réalisé en équipe avec une méthodologie Agile. Utilisation de Git et Trello pour le suivi des tâches. Rédaction complète d'un dossier d'architecture technique justifiant les choix (Natif vs Framework, PostgreSQL vs SQLite).

🛠️ Savoir-faire acquis

  • Conception d'une architecture MVC robuste sans dépendance à un framework.
  • Mise en place d'un pont applicatif (PHP exécutant des scripts Python).
  • Gestion de la confidentialité des données de santé (Introduction aux normes RGPD).
  • Travail collaboratif (Git).
