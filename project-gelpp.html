GELPP — Gestionnaire d'événements

Projet — Application Java/JavaFX pour la gestion d'événements en copropriété.

Cliquez sur les images pour les agrandir

🎯 Description

Dans le cadre de notre projet, nous avons conçu et développé GELPP (Gestionnaire d'Événements pour les Lotissements et Propriétés Partagées), une application lourde destinée à faciliter la gestion d'événements (assemblées générales, réunions, fêtes de voisinage) au sein des copropriétés. L'application est développée en Java avec JavaFX pour fournir une interface graphique ergonomique et conforme aux besoins métiers.

❓ Problématique

La gestion d'événements en copropriété est souvent dispersée (emails, affichages papiers, tableurs). GELPP centralise les informations, simplifie la planification, et améliore la communication entre gestionnaires et résidents.

🧠 Compétences mobilisées

  • Java & JavaFX (IHM et logique métier)
  • Modélisation UML (Visual Paradigm)
  • Contrôle de versions (Git / GitHub)
  • Méthodes agiles et gestion de projet

🎯 Objectifs

  • Permettre la création, la planification et le suivi d'événements
  • Offrir une interface intuitive pour les gestionnaires
  • Faciliter la communication et l'archivage des compte-rendus

🤝 Travail en équipe

Le projet a été réalisé par une équipe de 4 à 5 personnes. Nous avons utilisé Discord pour la communication, GitHub pour le code et Visual Paradigm pour la modélisation. Chaque membre avait des responsabilités claires (IHM, backend, tests, documentation).

👤 Apports individuels

Contribution au développement Java/JavaFX, à la conception des maquettes et à la rédaction des documents de cadrage. Participation aux revues de code et aux tests d'intégration.

🛠️ Savoir-faire acquis

  • Réalisation d'une application Java complète
  • Modélisation et conception logicielle
  • Travail collaboratif et gestion de versions
